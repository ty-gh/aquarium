# aquarium

店舗の 32 インチモニターで流しっぱなしにする「水槽」の HTML。眺めるためのもので、操作要素は持たない。lofi 的な雰囲気。

見た目だけが違う 3 案がある。依頼主に 1 つ選んでもらう。

## 3 案

| 案 | ファイル | 見た目 | 魚 |
|---|---|---|---|
| A | `pixel.html` | ピクセルアート（320×180 を拡大・32 色） | 5 種 19 匹 |
| B | `paper.html` | フラットな切り絵イラスト（くすんだ 12 色） | 5 種 17 匹 |
| C | `glow.html` | やわらかい光のグラデーション（暗めの室内向け） | 5 種 20 匹 |

昼・夕・夜の画面は `shots/` にある（`pixel_day.png`、`paper_dusk.jpg` など）。

`aquarium.html` は 3 案を 1 ファイルにまとめたもので、画面上のボタンで切り替えられる。

## URL

| 開くもの | URL |
|---|---|
| 切り替え付き | https://ty-gh.github.io/aquarium/ |
| 案を指定して開く | https://ty-gh.github.io/aquarium/?style=paper （`pixel`・`paper`・`glow`） |
| 1 案だけ | https://ty-gh.github.io/aquarium/paper.html （`pixel.html`・`glow.html` も同じ） |

開くときだけネット接続が要る。`main` に push すると数分で反映され、機器の側は再読み込みで新しくなる。

## 使い方

URL を開くか、HTML を機器にコピーして開く。

1. 再生する機器に HTML を 1 つコピーする（ほかのファイルは要らない。ネット接続も要らない）
2. ブラウザで開く
3. 全画面にする（Windows は F11、Mac は control + command + F）

20 分で昼 → 夕方 → 夜 → 昼と色が移る。

`aquarium.html` での切り替え:

| 操作 | 動き |
|---|---|
| マウスを動かす・画面に触れる | 下にボタン（ピクセル／切り絵／光）が出る。3 秒で消える |
| ボタンを押す | その案に切り替わる |
| 1・2・3 キー | ピクセル・切り絵・光に切り替わる |
| ← → キー | 前後の案に切り替わる |

選んだ案はブラウザが覚え、次に開いたときもその案で始まる。`aquarium.html?style=paper` のように開くと、その案で始まる（`pixel`・`paper`・`glow`）。

`aquarium.html` と `index.html`（URL の入口。中身は同じ）は `pixel.html`・`paper.html`・`glow.html` から作る。3 つのどれかを直したら `node build.mjs` で作り直す。

全画面の操作は実機で試していない。Mac の Chrome はツールバーが残る設定のことがある（「表示」メニューで外す）。

## 状態（2026-11-25）

3 案とも、制作 → 統括の確認 → 添削 1 回 → 再確認まで済み。

確かめたこと（3 案とも・Mac のヘッドレス Chrome で実時間再生）:

- 60fps で動く
- 1920×1080・縦置き 1080×1920・3840×2160 で全面に表示される
- コンソールエラーと外部通信が無い
- 600 倍速で 5 時間半ぶん進めても、魚・泡・粒の数が増えない
- 1.5 秒おき 16 コマ（24 秒ぶん）を並べて見て、魚が飛んだり急に現れたりしない

未確認:

- 動いている画面を人の目で続けて見ること（確かめたのは静止画とコマ並べまで）
- 実機のモニターでの見え方（色・明るさ・離れて見たときの魚の大きさ）
- 再生する機器での動作の軽さ（機器が未定）
- 何日も続けて流したときの挙動（確かめたのは早送りまで）
- Chrome 以外のブラウザ

## 添削後に残っている点

修正は各案 1 回で締めたので、直していない。

| 案 | 残っている点 |
|---|---|
| A | 群れの並びがやや規則的。魚が向きを変える回数が添削前より増えた（1 匹あたり 1 分に約 1 回 → 1.4〜2.7 回）。添削で「左右どちらかに 7 割以上寄らない」を求めた結果で、落ち着きなく見えないかは未確認 |
| B | 夕方の桃色が強く、主役の金魚が水の色に近づく。縦置きでは魚のひれが短時間重なる |
| C | 主役のエンゼルフィッシュが灰色の縞で地味。底の魚どうしが重なる場面がある |

## 修正前の版

- `before/paper.html`・`before/glow.html`
- `before/shots/` に 3 案の昼・夕・夜の画面
- A 案の修正前は HTML が残っておらず、画面だけ

## 検証用の口

画面には何も出ない。

- `?speed=N` で時間の進みを N 倍にする（例: `pixel.html?speed=60` で 20 秒が 1 周）
- ブラウザのコンソールで `__stats()` を呼ぶと、魚・泡・粒の現在数が返る

## 共通の仕様

- 魚 4〜5 種・14〜22 匹（群れ 1 種・大きめの主役 1 種・底にいる種 1 つ）、揺れる水草、岩と流木、砂底、ときどき立ちのぼる泡、光の筋、漂う粒
- 文字・時計・ロゴ・操作 UI・音は無い。マウスとキーに反応しない。カーソルは隠す
- 魚・泡・粒の数に上限がある。Canvas 2D のみ。内部の描画サイズに上限がある
- HTML 1 ファイルで完結し、`file://` で開いて動く
