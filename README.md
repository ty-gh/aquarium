見た目だけが違う 3 案を作り、依頼主に 1 つ選んでもらう。

## 再開の手順

1. A 案は `pixel.html` を続きから直す。B・C 案は下の仕様で新しく作る（Opus のサブエージェントに 1 案ずつ渡す。互いのファイルには触らせない）
2. 各案をヘッドレス Chrome で PNG に書き出し、画像を見て直す
3. 統括側で 3 案とも 1920×1080・縦置き 1080×1920・4K の描画、コンソールエラー、`?speed=120` で進めたあとの `__stats()` を確かめる
4. スクリーンショットを付けて 3 案を出し、選んでもらう

書き出しのコマンド（`CVDisplayLinkCreateWithCGDisplay failed` の行は無視してよい）:

```
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --hide-scrollbars --window-size=1920,1080 --virtual-time-budget=8000 --screenshot=<出力先.png> "file:///path/to/aquarium/pixel.html"
```

## 3 案共通の仕様

機能は 3 案で揃える。違うのは見た目だけ。

画面に出すもの:

- 魚 4〜5 種・合計 14〜22 匹。小さな群れ（6〜9 匹）が 1 種、大きめでゆっくり泳ぐ主役級（1〜2 匹）が 1 種、底にいる種が 1 つ
- 揺れる水草（奥と手前で層を分ける）、岩や流木、砂底
- 底の 1〜2 か所からときどき立ちのぼる泡
- 水面から差す光の筋と、水中を漂う細かい粒
- 20 分ほどの周期での色味の移ろい（昼 → 夕方 → 夜 → 戻る）

画面に出さないもの:

- 文字・時計・ロゴ・操作 UI・デバッグ表示・音。マウスやキーへの反応もなし。カーソルは隠し、スクロールバーと余白を出さない

動き:

- 形は大きめ、動きはゆっくり、急な方向転換なし
- 魚は端で向きを変えるか、画面外へ抜けて戻る。画面内で突然現れたり消えたりしない
- 一定周期で全体が巻き戻る作りにしない

流しっぱなしへの耐性:

- 魚・泡・粒の数に上限を設け、配列を増やし続けない
- `requestAnimationFrame` の dt を上限でクランプし、角度などは周期で折り返す
- Canvas 2D のみ。WebGL と全画面のぼかしは使わない。内部の描画サイズに上限を設ける
- どんな解像度・縦横でも全面を埋め、リサイズに追従する

自己完結:

- HTML 1 ファイルに CSS と JS を内包。外部の CDN・フォント・画像・通信なし。`file://` で開いて動く

検証用の口（画面には出さない）:

- `?speed=N` で時間の進みを N 倍にする
- `window.__stats()` が魚・泡・粒の現在数を返す

## 各案の見た目

A 案 `pixel.html`:

- 320×180 前後の内部バッファに描き、補間なしで拡大する
- 16〜32 色の限定パレット。深い青緑に暖色の差し色
- 魚は 2〜3 コマの尾びれアニメ。内部解像度で横 12〜40px
- 濃淡は色帯とディザで出す。ぼかし・発光・アンチエイリアスは使わない

B 案 `paper.html`:

- 輪郭線なしのベタ塗りの形を重ねる。彩度を落とした 8〜12 色（青緑・砂色・珊瑚色・からし色など）
- 奥行きは 4〜5 枚の層の重なりと、奥ほど水の色に溶ける色の差で出す
- 魚はベジェ曲線のシルエットで、体と尾がしなる。種類ごとに体形を変える
- 光の筋は薄い色の平たい帯。仕上げに、あらかじめ作ったノイズタイルを薄く重ねる
- 発光・ぼかし・写実的なグラデーションは使わない

C 案 `glow.html`:

- 深い藍〜青緑のなめらかなグラデーションの水。上からの光がやわらかく広がり、底は暗い
- 魚・水草・岩はグラデーションで丸みを出し、奥のものは水の色に霞む。1〜2 種の魚はほんのり発光する
- 光のにじみは、オフスクリーンに焼いた放射グラデーションを `lighter` で重ねる。毎フレームの `filter: blur` と `shadowBlur` は使わない
- 輪郭線・ベタ面・ドット絵表現・ネオン色は使わない。暗すぎて見えない絵にしない
